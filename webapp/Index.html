Bulk backfill — Ageing (Excel / CSV)

Each ageing row links to a production lot. Put the Lot ID if you know it, otherwise fill Casting No + Section No + Produced Date and it is matched automatically. Result defaults from Webster (or Pass). Rows matching no lot are skipped and listed.

⚠ Danger zone — delete production data

Deletes production lots (and their ageing + variance flags) for a date range. Anything already packed in that range blocks the delete, so stock is safe. Needs the Admin PIN. Cannot be undone.
